# ECS657U-Platformer-Main
Main repository for Platformer game where source code is located

# How to play 
Access the WebGL build using the link below:

https://never-95.github.io/ECS657U-Platformer-Builds/prototype%20v1.1/

# Controls
W / ↑ : Move Forward

A / ← : Move Left

S / ↓ : Move Backward

D / → : Move Righ

SpaceBar : Jump

# Access game in Unity
1. Clone project into your local machine

   `git clone https://github.com/Never-95/ECS657U-Platformer-Main.git`
   
2.Open Unity Hub and select the cloned project folder

  Make sure the Unity version matches the version of the project

# Testing the Project

1.Open the Scenes folder and load the main scene.

2.Press the Play button in Unity to test gameplay features.
